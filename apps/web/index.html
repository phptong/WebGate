WebGate

Web-ready mode. Chrome Extension remains the primary complete product entry; this page now supports browser-side WebLLM as an MVP.

Server / Ollama

Calls the local WebGate Flask server on the same origin, which then calls Ollama. Start the server first with cd server && python main.py, then open http://127.0.0.1:5000/apps/web/index.html.

Browser WebLLM

Runs the model directly in the browser using WebGPU. First load can be slow because model files need to download and cache locally.

WebGPU is not available. Use a recent Chrome/Edge browser and open this page from http://localhost or HTTPS.
